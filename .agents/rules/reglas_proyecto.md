# Reglas Operativas del Proyecto

## Regla de Consultas con Signo de Interrogación
- Si el usuario realiza una consulta con signo de interrogación (`?` o `¿`), **NO se debe generar ni actualizar el Plan Maestro**.
- Se debe responder **únicamente por pantalla / chat**, respondiendo directamente a la consulta.
- Solo las solicitudes de implementación, configuración o cambios técnicos generan o actualizan el plan incremental en [`PLAN_MAESTRO.md`](../../PLAN_MAESTRO.md).
